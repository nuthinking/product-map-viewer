# Tasko

Tasko is a personal and team task manager: capture tasks fast, plan the day, share projects. Used by individuals for personal to-dos and by small teams that share projects.

## Major capabilities

- **Tasks**: add tasks in plain language, organize them in projects, schedule them, complete them, label and filter them. See [Feature Map](features.md#tasks).
- **Collaboration**: share projects, assign tasks, discuss in comments. See [Feature Map](features.md#collaboration).
- **Account**: sign up, log in, manage the Free or Pro subscription. See [Feature Map](features.md#account).

## Major flows

- [Add a task](flows/add-task.md): capture a task from anywhere, with dates and project recognized from plain text.
- [Plan the day](flows/plan-the-day.md): review Today, reschedule overdue tasks and work through the list.
- [Complete a recurring task](flows/complete-recurring-task.md): check off a repeating task and get the next occurrence.
- [Share a project](flows/share-project.md): invite people to a project and work on its tasks together.
- [Get started](flows/onboarding.md): create an account and land in the app with a first task.
- [Upgrade to Pro](flows/upgrade.md): move from Free to Pro to unlock reminders and unlimited filters.

## About this folder

This is the Product Map: a description of what the product does and how it behaves, maintained alongside the code. `features.md` lists capabilities; `flows/` shows how users accomplish goals. Keep it about observable behavior, not implementation. Validate with `npm run product-map -- validate`.
